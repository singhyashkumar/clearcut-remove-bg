# Clearcut SEO, GEO and AEO roadmap

Updated: 13 November 2026

## Goal

Build qualified organic discovery for Clearcut around image background removal while keeping every claim accurate. The initial focus is English-language search intent in India and globally for:

- background remover
- remove background from image
- remove bg online free
- transparent background maker
- product, portrait, animal and car background removal

No implementation can guarantee first place. The practical sequence is to earn indexing, impressions, top-50 visibility, top-20 visibility and then top-10 positions for selected queries.

## Keyword-to-page map

| Search intent | Primary page | Purpose |

The homepage remains the only page targeting the broad commercial phrase. New pages must answer a distinct need so they do not cannibalize it.

## Phase 1 — search appearance and crawlability

- Publish a stable, crawlable favicon in ICO and PNG sizes.
- Keep the preferred site name consistently “Clearcut” in page metadata and `WebSite` structured data.
- Provide `Organization`, `WebApplication`, breadcrumb and factual FAQ structured data.
- Maintain one canonical URL per page, a complete XML sitemap and an unrestricted robots file.
- Verify every important URL returns 200 without login and that the built HTML contains its content.
- Request recrawling of `/`, `/about/` and the sitemap in Google Search Console after major releases.

## Phase 2 — answer quality for SEO, GEO and AEO

- Put a direct answer near the top of every guide before detailed explanation.
- Keep factual limitations visible: supported formats, model download sizes, local processing, one-photo workflow and unsupported platforms.
- Use descriptive headings that match real questions rather than repeating keywords unnaturally.
- Add original demonstrations, measured test cases and dated methodology pages. These are stronger citation targets than generic marketing copy.
- Maintain `llms.txt` as a concise map to authoritative pages. This is an accessibility aid for some AI systems, not a guaranteed ranking factor.
- Never add fabricated author credentials, statistics, comparisons or customer ratings.

## Phase 3 — authority and links

- Claim and fully complete the genuine Clearcut Trustpilot profile, then link it only after its exact public URL is verified.
- Ask real users for honest reviews without payment, required wording or pressure for a positive rating.
- Publish the open-source implementation, technical explanations and reproducible quality tests that other sites can cite.
- Seek relevant links from photography, ecommerce, privacy, browser-AI and open-source communities. Avoid bulk directory submissions and paid link packages.
- Create a transparent comparison page only after running repeatable tests against named alternatives and recording dates, inputs and output dimensions.

## Phase 4 — performance and conversion

- Track Core Web Vitals, especially the hero animation, JavaScript bundle and first model download messaging.
- Keep the upload action visible immediately and avoid blocking the tool behind sign-in.
- Preserve older hashed assets long enough to prevent cached HTML from producing 404 errors.
- Measure organic landing-page visits, successful processing starts and downloads without collecting uploaded photos.

## Measurement cadence

Weekly: Search Console indexing, crawl errors, query impressions, average position and click-through rate.

Monthly: landing-page conversions, branded searches, earned referring domains, Trustpilot visibility and the top gaining/losing queries.

Quarterly: content accuracy, outdated claims, competitor changes, internal links and technical performance.

## Immediate implementation batch

1. Stable favicon and site identity metadata.
2. `Organization` and factual FAQ structured data.
3. `llms.txt` with authoritative links and limitations.
4. Search Console recrawl of the homepage, About page and sitemap.
5. Baseline query export before further content changes.
